Картотека подвижных игр — PWA

Содержимое:
- index.html — текущая версия картотеки, подготовленная для PWA
- manifest.json — описание приложения для iPhone
- service-worker.js — офлайн-кэш
- icons/ — иконки приложения

Важно:
Для установки PWA на iPhone через Safari нужен HTTPS-сайт (исключение — localhost для разработки).
После публикации на HTTPS откройте страницу в Safari → Поделиться → На экран «Домой».

Данные самой картотеки по-прежнему сохраняются через localStorage, а экспорт/импорт резервной копии остаётся в приложении.
