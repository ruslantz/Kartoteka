Картотека подвижных игр — PWA (100 игр)

Содержимое:
- index.html      — страница приложения (разметка, стили, логика: поиск, фильтры, форма добавления/редактирования игр)
- games-data.js   — отдельная база данных: все 100 игр (название, группа, качества, сезон, ход игры, текст потешки). Редактируется независимо от index.html.
- manifest.json   — описание приложения для установки на iPhone/Android
- service-worker.js — офлайн-кэш (кэширует все файлы приложения при первом запуске)
- icons/          — иконки приложения

Как пользоваться офлайн (без хостинга):
Просто откройте index.html в любом браузере — работает полностью локально,
интернет не нужен. Правки (свои игры, изменения, удаления) хранятся в
localStorage браузера на этом устройстве.

Важно про PWA-установку («на экран Домой» с иконкой и офлайн-кэшем через
service-worker):
Service Worker по требованию браузеров работает только на HTTPS (или
localhost) — просто открыть index.html как локальный файл для этого
недостаточно. Если хотите полноценную PWA-установку:
1. Разместите все файлы (index.html, games-data.js, manifest.json,
   service-worker.js, icons/) на любом бесплатном HTTPS-хостинге
   (например, GitHub Pages, Netlify, Vercel).
2. Откройте получившийся HTTPS-адрес в Safari на iPhone.
3. Нажмите «Поделиться» → «На экран «Домой»».
Если такой хостинг не нужен — просто пользуйтесь index.html локально,
как обычным файлом; все функции (поиск, фильтры, добавление игр)
работают и без этого, единственное отличие — не будет отдельной иконки
и предзагруженного офлайн-кэша через service-worker.

Перенос правок между устройствами:
Кнопки «экспорт резервной копии» / «импорт из файла» внизу страницы
сохраняют и загружают .json-файл со всеми вашими добавленными и
изменёнными играми — так можно перенести правки с компьютера на iPhone
и обратно.
